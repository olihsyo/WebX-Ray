১. প্রজেক্ট পরিচিতি ও আর্কিটেকচার (Introduction & Purpose)
================================================================================
WebX-Ray AI হলো একটি অত্যাধুনিক Website Intelligence এবং AI Reconstruction Platform।
সহজ কথায়, আপনি যদি কোনো ওয়েবসাইটের লিঙ্ক দেন, এটি একটি ভার্চুয়াল হেডলেস ব্রাউজার
(Chromium) চালিয়ে পুরো ওয়েবসাইটটিকে "X-Ray" বা ব্যবচ্ছেদ করে ফেলে।

মূল কাজসমূহ:
- ওয়েবসাইটের সম্পূর্ণ ডিজাইন সিস্টেম (কালার প্যালেট, ফন্ট, স্পেসিং, বর্ডার, শ্যাডো) বের করা।
- রি-ইউজেবল UI কম্পোনেন্ট (হেডার, নেভবার, ফুটার, বাটন, কার্ড, ফর্ম) আলাদা করে শনাক্ত করা।
- ব্যাকগ্রাউন্ড নেটওয়ার্ক ও REST API কলগুলো রেকর্ড করে তাদের JSON স্কিমা রিভার্স-ইঞ্জিনিয়ার করা।
- ডাটাবেজ DDL স্কিপ্ট বিশ্লেষণ করে ভিজ্যুয়াল Mermaid ER Diagram তৈরি করা।
- এআই কোডিং এজেন্টদের (Antigravity, Cursor, Claude Code, Gemini) জন্য ১৫টি ফাইলের
  একটি রেডিমেড Master Reconstruction Package ও প্রম্পট তৈরি করা যাতে নতুন করে হুবহু সাইটটি
  ডেভেলপ করা যায়।
- নতুন ডেভেলপ করা সাইট ও মূল সাইটের পিক্সেল পারফেক্ট তুলনা (Perceptual SSIM) করা।

২. সিস্টেম রিকোয়ারমেন্টস (System Prerequisites)
================================================================================
- অপারেটিং সিস্টেম: Windows 10/11, macOS, অথবা Linux (Ubuntu 20.04+)
- পাইথন: Python 3.12 অথবা Python 3.13 (Python 3.13 সম্পূর্ণরূপে টেস্টেড ও সাপোর্টেড)
- নোড: Node.js 18+ বা 20+ (Node.js 24 সাপোর্টেড) এবং npm
- ব্রাউজার বাইনারি: Playwright Chromium (স্বয়ংক্রিয় কমান্ড দিয়ে ইনস্টল করা যায়)

৩. পূর্ণাঙ্গ ইন্সটলেশন নির্দেশিকা (Step-by-Step Installation)
================================================================================

ধাপ ১: রিপোজিটরি ক্লোন বা ফোল্ডারে প্রবেশ
-----------------------------------------
git clone https://github.com/olihsyo/WebX-Ray.git
cd WebX-Ray

ধাপ ২: পাইথন ভার্চুয়াল এনভায়রনমেন্ট (Virtualenv) তৈরি ও অ্যাক্টিভেশন
-------------------------------------------------------------------
python -m venv venv

# উইন্ডোজে (PowerShell):
.\venv\Scripts\Activate.ps1
# অথবা উইন্ডোজে (CMD):
.\venv\Scripts\activate.bat
# ম্যাক / লিনাক্সে:
source venv/bin/activate

ধাপ ৩: পাইথন লাইব্রেরি ও Playwright ব্রাউজার ইনস্টল
--------------------------------------------------
pip install -r backend/requirements.txt
playwright install chromium

ধাপ ৪: এনভায়রনমেন্ট ফাইল (.env) তৈরি
------------------------------------
রুট ফোল্ডারে থাকা .env.example ফাইলটি কপি করে .env তৈরি করুন:
copy .env.example .env   (উইন্ডোজ)
cp .env.example .env     (ম্যাক/লিনাক্স)

ঐচ্ছিক: .env ফাইলে আপনার Gemini, OpenAI বা Anthropic API Key যোগ করতে পারেন।
(API Key না দিলেও অফলাইন হিউরিস্টিক ইঞ্জিন স্বয়ংক্রিয়ভাবে কাজ করবে।)

ধাপ ৫: ফ্রন্টএন্ড সেটআপ
----------------------
cd frontend
npm install
cd ..

================================================================================
৪. অ্যাপ্লিকেশন চালু করার নিয়ম (How to Run Application)
================================================================================

পদ্ধতি ১: উইন্ডোজ ১-ক্লিক স্টার্ট (সবচেয়ে সহজ)
-----------------------------------------------
প্রজেক্টের রুট ফোল্ডারে থাকা start.bat ফাইলটিতে ডাবল ক্লিক করুন।
এটি ব্যাকএন্ড (Port 8000) এবং ফ্রন্টএন্ড (Port 5173) একসাথে আলাদা উইন্ডোতে চালু করে দেবে।

পদ্ধতি ২: টার্মিনাল থেকে ম্যানুয়ালি চালু করা
-------------------------------------------
১. ব্যাকএন্ড চালু করা (Port 8000):
   .\venv\Scripts\python.exe -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --reload --loop none

   - ব্যাকএন্ড সার্ভার: http://localhost:8000
   - সোয়াগার ইন্টারেক্টিভ API ডকস: http://localhost:8000/docs
   - রিডক ডকুমেন্টেশন: http://localhost:8000/redoc

২. ফ্রন্টএন্ড চালু করা (Port 5173):
   cd frontend
   npm run dev

   - ওয়েব ড্যাশবোর্ড: http://localhost:5173

৫. প্ল্যাটফর্মের ২৪টি ফিচারের বিস্তারিত ব্যবহার নির্দেশিকা (All 24 Screens & Features)
================================================================================

[১] Overview Dashboard (রুট পাথ: /)
-----------------------------------
- বিবরণ: এটি পুরো অ্যাপ্লিকেশনের সেন্ট্রাল কন্ট্রোল প্যানেল।
- কাজ: বর্তমান সক্রিয় টার্গেট ওয়েবসাইটের স্থিতি, সংগৃহীত পেজ সংখ্যা, মোট কম্পোনেন্ট,
  নেটওয়ার্ক API সংখ্যা এবং ডিজাইন টোকেনগুলোর দ্রুত সারাংশ কার্ড আকারে দেখা যায়।
- কীভাবে ব্যবহার করবেন: সাইডবারের একদম উপরে "Overview Dashboard"-এ ক্লিক করলেই এটি দেখতে পাবেন।

[২] Create Project (পাথ: /projects/new)
---------------------------------------
- বিবরণ: নতুন কোনো ওয়েবসাইট বিশ্লেষণ করার জন্য একটি প্রজেক্ট তৈরি করার পেজ।
- কাজ: টার্গেট ওয়েবসাইটের URL ও অ্যাক্সেস প্রোফাইল কনফিগার করে ডাটাবেজ ইনিশিয়ালাইজ করা।
- কীভাবে ব্যবহার করবেন:
  ১. Project Name লিখুন (যেমন: miah.shop বা StarTech)।
  2. Target Website URL দিন (যেমন: https://miah.shop)।
  3. Access Profile নির্বাচন করুন:
     - Public Website Analysis: সাধারণ যেকোনো পাবলিক ওয়েবসাইটের নিরাপদ ক্রলিংয়ের জন্য।
     - Authenticated Test Environment: লগইন বা স্যান্ডবক্স ক্রেডেনশিয়াল প্রয়োজন এমন সাইটের জন্য।
     - Owner-Provided Source Repository: লোকাল সোর্স কোড ফোল্ডার অ্যাটাচ করার জন্য।
     - Authorized Database Schema: কাস্টম SQL DDL ফাইল বিশ্লেষণের জন্য।
  4. "Initialize Project" বাটনে ক্লিক করুন।

[৩] Scan Configuration (পাথ: /scans/config)
-------------------------------------------
- বিবরণ: ব্রাউজার ক্রলার কীভাবে এবং কতদূর পর্যন্ত সাইটটি স্ক্যান করবে তা নির্ধারণের পেজ।
- কাজ: ক্রলিং মোড, পেজ লিমিট, ম্যাক্স ডেপথ ও ভিউপোর্ট কনফিগার করা।
- কীভাবে ব্যবহার করবেন:
  ১. Crawl Mode সিলেক্ট করুন:
     - Internal-Link Dynamic Crawl: পেজের ভেতরের অভ্যন্তরীণ লিংকগুলো ব্রাউজার দিয়ে ক্রল করে (রেকমেন্ডেড)।
     - Sitemap-Based Crawling: ওয়েবসাইটের sitemap.xml ফাইল থেকে সব লিংক খুঁজে আনে।
     - Browser-Assisted SPA Crawl: Next.js, React বা Vue সিঙ্গেল পেজ অ্যাপের জন্য।
  ২. Max Pages (যেমন: ১০ বা ২৫) এবং Max Depth (১ থেকে ৫) নির্ধারণ করুন।
  ৩. "Start Dynamic Browser Scan" বাটনে ক্লিক করুন।

[৪] Live Scan Monitor (পাথ: /scans/monitor)
------------------------------------------
- বিবরণ: লাইভ ক্রলিং ট্র্যাকিং মনিটর।
- কাজ: ব্রাউজার বর্তমানে কোন ইউআরএল ভিজিট করছে, প্রগ্রেস বার কত শতাংশ হয়েছে এবং কনসোল লগ
  ডায়াগনস্টিকস রিয়েল-টাইমে প্রদর্শন করা।
- কীভাবে ব্যবহার করবেন: স্ক্যান শুরু হওয়ার পর এই পেজে স্বয়ংক্রিয়ভাবে প্রগ্রেস দেখা যাবে।

[৫] Page Explorer (পাথ: /pages)
------------------------------
- বিবরণ: সাইটের ডিসকভার হওয়া প্রতিটি পেজের সম্পূর্ণ তালিকা ও ভিজ্যুয়াল প্রিভিউ।
- কাজ: রাউট অনুযায়ী পেজ টাইপ ক্লাসিফিকেশন (home, landing, product, auth, detail),
  HTTP স্ট্যাটাস (যেমন 200), এবং ফুল পেজ স্ক্রিনশট দেখা।
- কীভাবে ব্যবহার করবেন: বাম পাশের তালিকা থেকে যেকোনো রাউটে ক্লিক করুন, ডান পাশে পেজটির
  স্ক্রিনশট এবং মেটাডাটা দেখতে পাবেন।

[৬] Browser Inspector (পাথ: /browser)
------------------------------------
- বিবরণ: মাল্টি-ডিভাইস রেসপন্সিভ প্রিভিউ ও রেন্ডার টাইমিং চেকার।
- কাজ: একই পেজ বিভিন্ন ভিউপোর্টে কেমন দেখায় তা পরীক্ষা করা।
- কীভাবে ব্যবহার করবেন: উপরে থাকা ভিউপোর্ট ট্যাবগুলো থেকে Desktop (1920x1080),
  Tablet (768x1024), অথবা Mobile (375x812) সুইচ করে রেসপন্সিভনেস চেক করুন।

[৭] DOM Explorer (পাথ: /dom)

- কাজ: ব্রাউজার রেন্ডার হওয়া মূল DOM নোডগুলোর হায়ারার্কি, CSS সিলেক্টর, প্রস্থ/উচ্চতা দেখা।
- কীভাবে ব্যবহার করবেন: ট্রি ভিউ থেকে যেকোনো ট্যাগে ক্লিক করে তার বাউন্ডিং বক্স ও কম্পিউটেড স্টাইল দেখুন।

[৮] CSS Inspector (পাথ: /css)

- কাজ: সাইটে কোন কোন কালার কতবার ব্যবহার হয়েছে, ফন্ট সাইজ এবং মার্জিন/প্যাডিং ফিল্টার করা।

[৯] Design System Viewer (পাথ: /design-system)
----------------------------------------------

৬.১ SSRF ফিল্টারে NAT64 IPv6 ইস্যু সমাধান
-----------------------------------------
- সমস্যা: স্ক্যান শুরু করার সময় এরর আসত:
  "Target URL Security Validation Failed: Access to private or local network address (64:ff9b::...) is forbidden by SSRF protection."
- কারণ: বাংলাদেশি অনেক ISP বা মোবাইল ব্রডব্যান্ড নেটওয়ার্ক DNS64/NAT64 ব্যবহার করে। ফলে miah.shop এর
  পাবলিক আইপি (216.198.79.1) কে IPv6 ফরম্যাটে 64:ff9b::d8c6:4f01 হিসেবে পাওয়া যাচ্ছিল।
  পাইথনের ipaddress লাইব্রেরি এই রেঞ্জকে "Reserved" চিহ্নিত করায় SSRF ফিল্টার ভুলবশত ব্লক করছিল।
- সমাধান: backend/app/services/security.py ফাইলে RFC 6052 NAT64 Well-Known Prefix
  (64:ff9b::/96) হ্যান্ডলিং যোগ করা হয়েছে। সিস্টেম এখন ভেতরের আসল IPv4 অ্যাড্রেসটি চেক করে এবং
  পাবলিক হলে অনুমোদন দেয়।

৬.২ উইন্ডোজে Playwright NotImplementedError ও Proactor Event Loop ফিক্স
------------------------------------------------------------------------
- সমস্যা: স্ক্যান শেষ হলেও Page Explorer-এ পেজগুলো "Untitled Document", স্ট্যাটাস "failed" এবং
  "No Screenshot Rendered" দেখাচ্ছিল।
- কারণ: উইন্ডোজে Uvicorn যখন --reload মোডে চলে, তখন এটি স্বয়ংক্রিয়ভাবে SelectorEventLoop ব্যবহার করে।
  উইন্ডোজের SelectorEventLoop সাব-প্রসেস চালাতে পারে না (_make_subprocess_transport raises NotImplementedError)।
  Playwright ব্রাউজার চালাতে সাব-প্রসেস প্রয়োজন হওয়ায় এটি ক্র্যাশ করছিল।
- সমাধান: 
  ১. backend/app/services/browser_engine.py ফাইলে প্রোঅ্যাক্টর থ্রেড র‍্যাপার যোগ করা হয়েছে।
     মেইন লুপ SelectorEventLoop হলেও Playwright স্বয়ংক্রিয়ভাবে ProactorEventLoop থ্রেডে চলে।
  ২. backend/app/main.py-তে WindowsProactorEventLoopPolicy নিশ্চিত করা হয়েছে।
  ৩. run-backend.bat ও run-backend.ps1 স্ক্রিপ্টে --loop none যুক্ত করা হয়েছে।
